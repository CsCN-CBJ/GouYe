# 项目分组视图 + 已完成项处理

## 核心诉求

需求、TODO、打卡三个模块按项目分组展示，项目区分醒目；已完成项不再与待办混杂，默认隐藏或弱化。记账页不动。三个模块各自独立的项目体系。

## 背景

当前三个非记账页面的共同问题：

1. **项目区分不明显**：项目名只是卡片上的小蓝标签，没有分组标题，一眼扫过去分不清哪些属于哪个项目
2. **无法按项目分类查看**：三个页面都是扁平列表，没有按项目聚合
3. **已完成项混杂**：TODO/需求默认显示所有状态，已完成和待办混在一起，视觉上也没有弱化（无删除线、无透明度降低）

打卡模块的"项目"就是模板（template），已有 template 关联，无需额外加 projectId。

## 方案

### 1. 打卡模块按模板分组

打卡的"项目"就是模板（CheckinTemplate）。每条 Checkin 已关联 template，直接按 template 分组即可，无需 schema 变更。

分组方式与需求/TODO 按项目分组一致：模板标题行（icon + 名称 + 计数）→ 卡片列表，但打卡分组有额外规则：

- **每组最多展示 5 条**，超出部分显示"还有 N 条"折叠提示
- **卡片内容预览**：按 template 的 fields_schema 渲染所有 payload 字段值（与当前逻辑一致），格式更紧凑——一行内联展示，如 `体重 72kg · 跑步 5km`

### 2. 三个页面统一分组视图

将三个页面的扁平卡片列表改为**按项目分组**的视图：

```
┌─────────────────────────────────────────┐
│ 📁 项目A (3)                            │  ← 项目标题行：名称 + 条目数
│ ┌─────────────────────────────────────┐ │
│ │ 卡片1                              │ │
│ │ 卡片2                              │ │
│ │ 卡片3                              │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ 📁 项目B (2)                            │
│ ┌─────────────────────────────────────┐ │
│ │ 卡片4                              │ │
│ │ 卡片5                              │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ 📂 未归类 (1)                           │  ← projectId 为 null 的条目
│ ┌─────────────────────────────────────┐ │
│ │ 卡片6                              │ │
│ └─────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

**项目标题行**：加粗项目名 + 条目计数 + 项目颜色标识（左侧色条），替代当前卡片上的小蓝标签。卡片内不再重复显示项目名。

**未归类分组**：没有关联项目的条目归入"未归类"分组，始终显示在最后。

**分组排序**：按项目名排序，"未归类"最后。

### 3. 已完成项处理

**TODO / 需求页面：**

- 默认筛选改为 `status=pending`（只显示待办），而非当前的"全部状态"
- 筛选栏保留"全部状态/待办/已完成/已取消"四个选项
- 已完成项在列表中视觉弱化：透明度降低（opacity-50）+ 标题加删除线（line-through）

**打卡页面：**

- 打卡没有状态概念，无需此处理

### 4. 筛选栏微调

**需求/TODO 筛选栏新增**：项目筛选下拉保留，但增加"按项目分组"的视觉分组（分组视图下项目筛选变为高亮指定项目分组）

**打卡筛选栏新增**：标签筛选下拉（API 已支持但 UI 未暴露）

## 功能范围

### 包含

- [ ] 三个页面（需求/TODO/打卡）改为按项目/模板分组视图
- [ ] 项目标题行：名称 + 计数 + 色条
- [ ] "未归类"分组（需求/TODO 中 projectId 为 null 的条目）
- [ ] TODO/需求默认筛选改为 pending
- [ ] 已完成项视觉弱化（opacity + line-through）
- [ ] 打卡每组最多 5 条 + "还有 N 条"折叠
- [ ] 打卡卡片 payload 字段紧凑展示（一行内联）
- [ ] 打卡筛选栏加标签下拉

### 不包含

- 记账页面改动
- Schema/API 变更（打卡无需加 projectId，按 template 分组）
- 项目颜色自定义（使用预设色板按项目 ID 取模分配）
- 移动端旧前端改动
- 创建/编辑/删除数据的 UI

## 测试与验收标准

1. 需求/TODO 页面：条目按项目分组显示，项目标题行醒目，"未归类"在最后
2. 打卡页面：条目按模板分组显示，每组最多 5 条 + 折叠提示，payload 字段紧凑展示，标签筛选下拉可用
3. 需求/TODO 默认只显示待办项；切换到"全部状态"后，已完成项有视觉弱化
4. 记账页面无变化
5. 手机端布局正常（分组视图在小屏上也要合理）
